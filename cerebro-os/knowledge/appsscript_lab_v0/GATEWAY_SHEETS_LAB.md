# Gateway de conocimiento LAB de solo lectura

Adaptador paralelo a Gateway, sin ampliación de OAuth del Apps Script ni cambios de producción. `gateway_sheets_lab.cjs` exige que el punto de entrada del Gateway inyecte la autenticación, el control de política y un registro auditable antes de responder. La identidad y las concesiones se obtienen del contexto autenticado. Las siete dimensiones se autorizan antes de contactar Google. El código usa la hoja fija, método GET y un resolver idéntico al instalado, fijado por SHA-256. Cada paquete requiere un recibo interno con el mismo hash. El registro contiene identidad, ámbito y resultado, sin contenido ni credenciales.

El consumidor dedicado es `cerebro-knowledge-reader-lab@cerebro-forge.iam.gserviceaccount.com`. Para la prueba en Cloud Shell requiere permiso Lector sobre la hoja concreta, Sheets API e IAM Service Account Credentials API habilitadas y un operador autorizado a emitir un token efímero para esa cuenta. La prueba solicita exclusivamente `spreadsheets.readonly`, mantiene los tokens en memoria y los descarta al salir. Para desplegar el lector debe usarse la identidad del runtime LAB autorizada para esa cuenta. Mantener el permiso restringido a la cuenta dedicada. El adaptador carece de endpoint externo y permanece desconectado del Gateway hasta que ese runtime e IAM sean verificados.

Con Node.js 20+ ejecutar `node gateway_sheets_probe.cjs CORREO_OPERADOR` dentro de Cloud Shell autenticado. El canario comprueba rechazo por empresa y versión, e intenta lecturas de Facebook, Instagram, LinkedIn y SEO. El código de salida 2 indica menos de tres lecturas respaldadas por recibo. La sonda es independiente de la interfaz de producción y sus concesiones son exclusivamente las cuatro identidades/versiones fijadas. Los logs de prueba son evidencia del canario, no consumo de agentes. Para la integración real, conectar política, identidad y auditoría del runtime en lugar de las dependencias del canario. No otorgar acceso a agentes ni actualizar certificaciones desde este módulo.

Rollback del canario: revocar en Drive la concesión Lector de la cuenta dedicada y retirar cualquier concesión IAM que se haya agregado específicamente para esta prueba. La fábrica y sus lotes son independientes del lector.
