# CEREBRO Browser Bridge Chrome Extension V1.3

LAB-only actuation proof.

It can only:
- contact 127.0.0.1;
- fetch a local LAB command from CEREBRO Browser Bridge;
- open the local CEREBRO LAB test page in a background tab;
- return a local completion receipt.

It cannot access arbitrary websites, cookies, passwords, login databases, DOM/content scripts, or external mutation surfaces.
