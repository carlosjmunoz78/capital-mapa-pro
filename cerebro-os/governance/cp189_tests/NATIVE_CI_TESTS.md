# Native tests evidence adapter (bounded historical rehearsal)
Pin one original candidate, exact source/merge, repository identifiers, signer workflow, artifact digest, manifest, predicate and trusted Rekor timestamp. Use gh attestation verify on bytes, not caller-supplied verification JSON. Only tests gate can pass, eleven missing gates remain BLOCKED, no deploy. The fixed historical attestation expires after 1h and is not a recurring CI gate: later runs must report expired/HOLD rather than repeat old evidence or change its timestamp. A general production adapter requires separately governed candidate policy, runtime trust provisioning, native bundle archival and freshness renewal. No changes to existing CP189 Ed25519 adapters. The native integration job is a one-shot regression rehearsal for this PR, not a release authority.
